# 캡처 대장 — 조립 화면 덱 (플랜 §25-3)

원본은 **개발(촬영용) 웹빌드**를 로컬 서버(`http://127.0.0.1:8000/`)로 열어
**캔버스 백버퍼에서 그대로** 뽑았다. 도구는 `Docs/portfolio/tools/` 에 있다.

**⚠️ 창 스크린샷으로는 규격이 안 나온다.** 미리보기 패널이 자기 크기(800×1428)로 줄여
잡는다. 캔버스에서 뽑아야 1440×2560 이 그대로 나온다.

**⚠️ 창 배율 125% 가 곱해진다.** 창을 1440×2560 으로 맞춰도 Unity 가
`devicePixelRatio` 를 곱해 백버퍼를 **1800×3200** 으로 잡았다. `devicePixelRatio` 를
1 로 눌러야 규격이 나온다(도구가 한다). **이것을 안 하면 그림이 캔버스 왼쪽 위 구석에만
그려진다** — 규격만 틀리는 것이 아니라 화면이 깨져 보인다.

**⚠️ 클릭도 캔버스 좌표로 넣어야 한다.** 미리보기 패널이 화면을 줄여 보여 주므로
패널의 클릭 좌표는 게임에 안 닿는다. 도구의 `mbiClick(x, y)` 이 캔버스 CSS 좌표로 넣는다.

## 표의 「⚠️」 셋 — 왜 그대로 두었나

- **IMG-04 미연결 경고** — 한쪽만 닿은 벨트를 **일부러 놓아야** 나온다. 보드를 편집하면
  다른 컷의 상태가 같이 바뀌므로 다음 차수로 미뤘다.
- **IMG-07 전력 부족** — 발전소를 지워야 하는데, **생산이 멈춘 보드에서는 지워도 안 뜬다.**
  공급 0·수요 0 은 「노드를 놓기 전」이라 경고가 아니다(`SupplyStopRules`). 생산이 도는
  상태를 먼저 만들어야 한다.
- **IMG-10 스테이지 3** — 스테이지 3 까지 진행하거나 골라 넣어야 한다.

## 모든 컷에 걸리는 두 가지

1. ⚠️ **「생산이 멈췄습니다」 경고 띠가 보드 한가운데를 가로지른다.** 씬을 열면 공급이
   0 이라 뜨는 것이며 결함이 아니다. 크롭으로 뺀 컷도 있고 든 컷도 있다 — 표를 볼 것.
   최종본에서는 **생산이 도는 상태로 다시 찍는 것이 낫다.**
2. ⚠️ **구역 이름표 글자가 잘려 나온다**(「대」·「모」·「팔」·「다」). 리허설 1차 ③ 으로
   올라간 **가시성 문제**이며, `260910_W02` 11-1 이 「이름표는 그대로 그린다 · 코드를
   걷지 않는다」로 판정했다. **자산으로 풀 자리**라 캡처가 고칠 수 있는 것이 아니다.

## 표와 달랐던 것 셋

- ⚠️ **품목은 12종이 아니라 열 종이다.** `Art/Items/` 에 열 개가 있고 `art_manifest` 도
  「품목 열 종」이라 적는다. IMG-09 는 **있는 그대로 열 종**이다.
- ⚠️ **배율 ×2.00~×2.50 을 못 맞췄다.** 화면의 「보드 배율」 표기가 **×1.00 에서 더
  올라가지 않는다.** 클로즈업은 **크롭**으로 대신했고 배율 칸에 **화면 표기 그대로** 적었다 —
  안 잰 것을 적지 않는다.
- ⚠️ **변수 패널이 하단이 아니라 오른쪽 위에 있다.** §25-3 은 「조립 화면 하단 변수 패널」이라
  적었는데 지금 화면은 오른쪽 위다. IMG-07 은 **오른쪽 위 패널**을 잘랐다.
