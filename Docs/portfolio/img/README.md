# 캡처 대장 — 조립 화면 덱 (플랜 §25-3)

원본은 **개발(촬영용) 웹빌드**를 로컬 서버(`http://127.0.0.1:8000/`)로 열어
**캔버스 백버퍼에서 그대로** 뽑았다. 도구는 `Docs/portfolio/tools/` 에 있다.

**⚠️ 창 스크린샷으로는 규격이 안 나온다.** 미리보기 패널이 자기 크기(800×1428)로 줄여
잡는다. 캔버스에서 뽑아야 1440×2560 이 그대로 나온다.

**⚠️ 창 배율 125% 가 곱해진다.** 창을 1440×2560 으로 맞춰도 Unity 가
`devicePixelRatio` 를 곱해 백버퍼를 **1800×3200** 으로 잡았다. `devicePixelRatio` 를
1 로 눌러야 규격이 나온다(도구가 한다). **이것을 안 하면 그림이 캔버스 왼쪽 위 구석에만
그려진다** — 규격만 틀리는 것이 아니라 화면이 깨져 보인다.

## 모든 컷에 걸리는 두 가지

1. ⚠️ **「생산이 멈췄습니다」 경고 띠가 보드 한가운데를 가로지른다.** 씬을 열면 공급이
   0 이라 뜨는 것이며 결함이 아니다. **크롭으로 뺀 컷도 있고 든 컷도 있다** — 표의
   비고를 볼 것. 최종본에서는 생산이 도는 상태로 다시 찍는 것이 낫다.
2. ⚠️ **구역 이름표 글자가 잘려 나온다**(「대」·「모」·「팔」·「다」). 리허설 1차 ③ 으로
   올라간 **가시성 문제**이며, `260910_W02` 11-1 이 「이름표는 그대로 그린다 · 코드를
   걷지 않는다」로 판정했다. **자산으로 풀 자리**라 캡처가 고칠 수 있는 것이 아니다.

## 갱신 셋 — 잰 결과

| 플랜 §25-3 의 전제 | 지금 |
|---|---|
| 720×1280 로 두고 2배 스케일 | **1440×2560 을 그대로 잡는다**(위의 두 함정 참조) |
| 보드 아트가 코드에 배선되지 않았다 | ✅ **배선됐다** — 노드·벨트·병합기·분류기가 그림으로 나온다. 팔레트 버튼에도 노드 스프라이트가 붙었다 |
| 발열 줄 · 분열 표기가 남아 있다 | ⚠️ **발열 줄만 남았다**(`UI/VariablePanel.cs:74`). **분열 표기는 없다** — UI 전수 검색 0건. 위 컷들은 변수 패널을 크롭으로 뺐다 |
