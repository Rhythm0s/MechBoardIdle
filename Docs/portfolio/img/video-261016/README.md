## ⚠️ 넷 — 왜 그대로 두었나

1. **보드 배율·시야를 못 옮겼다.** 배율 단추가 없고(휠도 안 먹음), 「이동 모드」에서 끌기를 합성 포인터로 넣으면 안 움직였다. 앱 브라우저의 실제 끌기는 시야를 옮겼지만 그 뒤 Unity 렌더 크기가 캔버스 왼쪽 위 구석으로 줄어(README 위 차수의 함정 그대로) 다시 띄워야 했다. 그래서 **기본 시야(칸 x 3~8 · y 4~9)** 안에서만 찍었다.
2. **변수 패널 없음** — 위 IMG-07.
3. **미연결 경고(IMG-04)** — 한쪽만 닿은 벨트를 일부러 놓아야 한다. 합성 끌기가 튜토리얼 빈 칸에 **벨트 대신 변환기**를 놓은 일이 두 번 있었다(이미 알려진 S-3 · 짧은 끌기가 탭으로 읽힘). 보드를 망칠 수 있어 경고 컷은 미뤘다.
