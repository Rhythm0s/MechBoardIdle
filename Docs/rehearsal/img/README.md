# 리허설 스크린샷 자리

결함 재현 스크린샷을 여기에 둔다 (2026-09-11 신설 · 플랜 §71-14 ②).

- 이름: `260911_<결함번호>_<무엇>.png` (예: `260911_defect1_mount0.png`)
- 찍을 때: **격자 좌표가 보이게** · **보드 배율 ×1.00**

⚠️ **스크린샷보다 「보드 좌표 덤프」가 낫다.** 심사자용 바로가기 패널의
「보드 좌표 덤프 (클립보드로)」를 누르면 **하네스가 그대로 읽는 글**이 클립보드에 들어간다 —
사람이 좌표를 옮겨 적지 않아도 되고, 옮겨 적다 한 칸 틀려 **게임과 다른 보드를 재는**
사고를 막는다(2026-09-11 에 실제로 있었던 사고다).
