## 2. 리허설 결함 ① 재현 — 물류가 마운트에 닿는가

> **결함 ①** = 「물류가 마운트에 안 닿는다」. 하네스에서는 **안 난다** — 사용자 화면에서만 났다.
> 그래서 **놓인 배치 그대로**가 필요하다.

### 2-1. 절차

| # | 할 것 | 어디 |
|---|---|---|
| 1 | 「▲ 전투로」로 전투 화면 → 심사자용 바로가기 펼치기 | 오른쪽 아래 |
| 2 | **「처음부터 (저장 초기화)」** 누르기 | 패널 아래쪽 |
| 3 | 튜토리얼이 처음부터 시작되는지 확인 | |
| 4 | 「▼ 조립」 → **고스트 칸 밖이 어두운가**(DIM) | 보드 |
| 5 | **팔레트에 「기초 군수」만 켜져 있는가**(나머지는 어둡게) | 부유 띠 |
| 6 | 빈 칸(고스트가 가리키는 자리)에 기초 군수 놓기 | |
| 7 | **막이 걷히고 팔레트가 전부 켜지는가** | |
| 8 | 「▲ 전투로」 → **마운트 재고가 오르는가** 관찰 | 상태창 |

### 2-2. 기대값 (하네스 실측 · `260911_V01` 1-3)

| 것 | 기대 | 관찰값 |
|---|---|---|
| 첫 도착까지 | **≈ 5.5초** | |
| 마운트 **0 → 40** 채움 | **≈ 16초** (5.5 + 40÷4) | |
| 정상상태 산출 | **≈ 4.0개/초** | |

⚠️ **빈 칸을 놓기 전에도 세 줄이 흐른다**(현행 배치) — 「놓기 전 0」이 **안 선다.**
이것은 **알고 있는 것**이고 `260911_V01` 2-1 판정 요청에 올라가 있다. 여기서 볼 것은
**놓은 뒤 마운트가 40까지 차는가**다.

### 2-3. 안 오르면 — 둘 중 하나를 남겨 주면 된다

**(가) 보드 좌표 덤프 (권장 · 자동)**

1. 「▲ 전투로」로 돌아가 심사자용 바로가기 → **「보드 좌표 덤프 (클립보드로)」**
2. 누르면 **클립보드에 들어간다** — 아무 데나 붙여 넣어 주면 된다
3. 버튼 글자가 「복사됨 1」로 바뀌면 떠진 것이다

> 이 글은 **하네스가 그대로 읽는 꼴**이다 — 노드/벨트의 좌표와 **면 전부**가 들어 있어
> 사람이 옮겨 적을 필요가 없다. (옮겨 적다 한 칸 틀려 **게임과 다른 보드를 재는** 사고가
> 오늘 실제로 있었다.)

**(나) 스크린샷** — 저장 자리 `Docs/rehearsal/img/`

- **격자 좌표가 보이게** · **보드 배율 ×1.00** 으로 맞춘 뒤 찍어 주면 된다

## 4. 효과음 여덟 — 게임 안에서 청취

⚠️ **소리가 나려면 먼저 아무 곳이나 한 번 클릭해야 한다** — 브라우저가 첫 제스처 전까지

| # | 사건 (게임에서 언제 나는가) | 파일 | 갈래 | 길이 | 뭉개짐 / 길다 / 괜찮다 |

| 1 | **노드를 격자에 놓는 순간** | `sfx_nodesnap` | 조작음 | ⚠️ 1.06초 (상한 0.5) | |
| 2 | **벨트가 올바른 면에 닿아 연결이 성립할 때** | `sfx_beltconnect` | 조작음 | ⚠️ 1.01초 (상한 0.5) | |
| 3 | **병목이 생긴 순간** (상태가 바뀔 때 **한 번만**) | `sfx_bottleneck` | **경고** | ⚠️ 1.03초 (상한 0.5) | |
