같은 mp3 를 같은 도구·같은 설정으로 두 번 변환해 md5 가 갈렸다. 원인을 재 보니
**7096바이트 중 24바이트만 다르고**(첫 자리 14~17), **디코딩한 PCM 은 완전히 같다**(최대 차이 0.0).

**그래서 「같은 파일인가」는 원본 mp3 md5 로 대조한다.** 위 표의 ogg md5 는
**지금 이 컴퓨터에 있는 변환본이 무엇인지**를 적어 둔 것일 뿐, 다시 받아 변환한 사람의 값과 다른 것이 정상이다.

⚠️ **이 자리에서 실제로 값이 한 번 갈렸다.** 구현-문서·코드 세션과 아트 세션이 각각 변환해 표의 값과
디스크의 파일이 어긋나 있었다. 위 표는 **디스크 실물에서 다시 찍은 값**으로 고쳤다.

### 임포트 규격 — `AudioImportRules` 가 sfx 에 먹이는 것 (2026-09-09 아트가 코드에서 읽음)

**「Decompress on load 가 먹는가」를 확인했다 — 먹는다.** `Assets/_Project/Scripts/Editor/AudioImportRules.cs`
의 `OnPreprocessAudio` 가 `Assets/_Project/Audio/sfx` 로 시작하는 경로에 아래를 먹인다.

| 항목 | 값 | 뜻 |
|---|---|---|
| `loadType` | **`DecompressOnLoad`** | 메모리에 풀어 둔다 — 짧은 소리가 초당 여러 번 나므로 재생 지연을 없앤다 |
| `compressionFormat` | `PCM` | 풀어 두므로 압축을 남기지 않는다 |
| `preloadAudioData` | `true` | 미리 읽는다 |
| `forceToMono` | **`true`** | ⚠️ **모노는 임포터가 만든다 — 파일은 스테레오다** |
| `loadInBackground` | `false` | sfx 는 배경 적재를 안 한다 (BGM 만 `true`) |

⚠️ **「모노 유지」의 실제 자리가 여기다.** 조달된 여덟이 전부 **스테레오**로 왔고 변환에서도 채널을 안 건드렸다 —
`sf.read(..., always_2d=True)` 로 원본 채널 수를 그대로 읽어 썼다. **파일을 모노로 내리지 않은 것은 의도다**:
출처 규약이 개변본까지 막고 있고, 임포트 규격의 진실 원천은 코드이므로(2026-09-09 규칙 개정)
파일을 고치면 규격이 두 곳에 살게 된다. 게임에서 나는 소리는 `forceToMono` 로 모노다.

⚠️ **BGM 둘은 이 규칙보다 먼저 리포에 들어왔다**(아트 `3658409`). `AudioImportRules` 의
`MBI/Reimport Audio` 메뉴를 한 번 돌려야 규격이 붙는다 — 코드 쪽에 그렇게 적혀 있다.

**규약은 개변을 막지 않는다** — 효과음ラボ가 금지한 것은 **재배포**이고, 자른 결과물도

|---|---|
| 자른 길이 | **0.480초** (상한 0.5 안) · 구 1.384초 |

### 재는 법과 변환 방법 (2026-09-09 · 구현-문서·코드 세션이 사용자 지시로 수행)

- **도구**: Python `soundfile` 0.14.0 (libsndfile 1.2.2). **`ffmpeg`이 없어 `pydub`을 못 썼고**,
  libsndfile 이 mp3 읽기와 OGG/Vorbis 쓰기를 둘 다 해서 **한 라이브러리로 끝냈다.**
- **변환**: `sf.read(mp3)` → `sf.write(ogg, format="OGG", subtype="VORBIS")`.
  표본율은 **그대로 두었다**(44.1/48 kHz 섞여 있다). 채널도 **그대로** — 여덟 다 스테레오다.
- **길이**: 디코드한 표본 수 ÷ 표본율. 도구가 낸 값이 아니라 **파일에서 직접 센 값**이다.

⚠️ **받았을 때는 여덟이 전부 길이 상한을 넘었다.** 사운드 문서 2장이 효과음을 **0.5초 이내**로 묶었고
`sfx_fusion`만 2.2초까지 열어 두었는데, 받은 실측은 **1.01초에서 3.97초**였다.
✅ **`sfx_fire_a` 하나만 잘랐다** (2026-09-10 · 위 절) — 나머지 일곱은 그대로이고 사용자 청취 뒤다.
⚠️ **길이를 묶은 근거가 살아 있다**(2장) — 이 게임의 소리는 초당 여러 번 나고
관통탄은 초당 다섯 발이다. **1초짜리가 초당 다섯 번 나면 겹쳐 뭉개진다.**
겹침 상한(잠정 3)이 그 뒤에 오는 두 번째 방어선이지 첫 번째가 아니다.

⚠️ **여덟 다 스테레오로 왔다.** 사운드 리스트는 효과음을 **모노**로 적어 두었다.
✅ **파일은 안 건드리고 임포트에서 내린다** — `AudioImportRules`가 sfx 에만
`forceToMono = true` 를 먹인다(2026-09-09). **규격의 소스가 코드**라는 새 규칙 그대로이며,
파일을 고치면 규격이 두 곳에 살고 **다시 받은 사람은 스테레오를 쓰게 된다.**

⚠️ **`sfx_fire_a` 는 이미 압축된 것을 다시 압축한 자리라 손실이 겹친다** — 받았을 때는
ogg 가 mp3 보다 컸다(22 KB > 17 KB). 09-10 에 0.48초로 자른 뒤에는 더 작아졌지만
**겹친 손실 자체는 남는다** — 원본을 wav 로 받을 수 있으면 그쪽이 낫다.

### 임포트 설정 — `AudioImportRules` 가 sfx 에 먹인 값

`OnPreprocessAudio` 가 `Assets/_Project/Audio/sfx` 로 시작하는 경로에
**`DecompressOnLoad` · `PCM` · `preloadAudioData = true`** 를 넣는다.
✅ **2026-09-09 확인 — 여덟 다 먹었다.** `.meta` 여덟이 생겼고 값을 직접 읽었다:

| 항목 | 값(원문) | 뜻 |
|---|---|---|
| `loadType` | `0` | **Decompress on load** — 메모리에 풀어 둔다(BGM 의 `2` = Streaming 과 반대) |
| `compressionFormat` | `0` | **PCM** — 풀어 두므로 압축을 남기지 않는다 |
| `preloadAudioData` | `1` | 미리 읽는다 — 첫 발에서 끊기지 않게 |
| `forceToMono` | `1` | **모노로 내린다** — 사운드 리스트의 「모노」를 임포트가 이행한다 |
| `loadInBackground` | `0` | 배경 적재 안 함 — 짧아서 필요 없다 |

⚠️ **`.meta` 는 커밋되지 않으므로 이 값은 각자의 Unity 가 임포트할 때마다 다시 먹인다** —
코드가 소스라 리포에 `.meta` 가 없어도 규격이 갈리지 않는다.
