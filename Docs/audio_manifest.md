⚠️ **ogg md5 는 대조용 값이 못 된다 — 변환이 결정적이지 않다** (2026-09-09 실측 · 아트).
같은 mp3 를 같은 도구·같은 설정으로 두 번 변환해 md5 가 갈렸다. 원인을 재 보니
**7096바이트 중 24바이트만 다르고**(첫 자리 14~17), **디코딩한 PCM 은 완전히 같다**(최대 차이 0.0).
Ogg 페이지 머리의 **스트림 일련번호가 변환할 때마다 새로 뽑히고** 그에 딸린 CRC 가 함께 바뀌는 것이다.

**그래서 「같은 파일인가」는 원본 mp3 md5 로 대조한다.** 위 표의 ogg md5 는
**지금 이 컴퓨터에 있는 변환본이 무엇인지**를 적어 둔 것일 뿐, 다시 받아 변환한 사람의 값과 다른 것이 정상이다.

⚠️ **이 자리에서 실제로 값이 한 번 갈렸다.** 구현-문서·코드 세션과 아트 세션이 각각 변환해 표의 값과
디스크의 파일이 어긋나 있었다. 위 표는 **디스크 실물에서 다시 찍은 값**으로 고쳤다.

### 임포트 규격 — `AudioImportRules` 가 sfx 에 먹이는 것 (2026-09-09 아트가 코드에서 읽음)

**「Decompress on load 가 먹는가」를 확인했다 — 먹는다.** `Assets/_Project/Scripts/Editor/AudioImportRules.cs`
의 `OnPreprocessAudio` 가 `Assets/_Project/Audio/sfx` 로 시작하는 경로에 아래를 먹인다.

| 항목 | 값 | 뜻 |
|---|---|---|
| `loadType` | **`DecompressOnLoad`** | 메모리에 풀어 둔다 — 짧은 소리가 초당 여러 번 나므로 재생 지연을 없앤다 |
| `compressionFormat` | `PCM` | 풀어 두므로 압축을 남기지 않는다 |
| `preloadAudioData` | `true` | 미리 읽는다 |
| `forceToMono` | **`true`** | ⚠️ **모노는 임포터가 만든다 — 파일은 스테레오다** |
| `loadInBackground` | `false` | sfx 는 배경 적재를 안 한다 (BGM 만 `true`) |

⚠️ **「모노 유지」의 실제 자리가 여기다.** 조달된 여덟이 전부 **스테레오**로 왔고 변환에서도 채널을 안 건드렸다 —
`sf.read(..., always_2d=True)` 로 원본 채널 수를 그대로 읽어 썼다. **파일을 모노로 내리지 않은 것은 의도다**:
출처 규약이 개변본까지 막고 있고, 임포트 규격의 진실 원천은 코드이므로(2026-09-09 규칙 개정)
파일을 고치면 규격이 두 곳에 살게 된다. 게임에서 나는 소리는 `forceToMono` 로 모노다.

⚠️ **BGM 둘은 이 규칙보다 먼저 리포에 들어왔다**(아트 `3658409`). `AudioImportRules` 의
`MBI/Reimport Audio` 메뉴를 한 번 돌려야 규격이 붙는다 — 코드 쪽에 그렇게 적혀 있다.

### ✅ `sfx_ui_click` · `sfx_goal_clear` 조달·설치 (2026-09-15 · 사용자 조달)

**소리 목록이 여덟에서 열로 늘었다.** 구 서술 「이름만 있고 파일이 없다」는 닫혔다 —
사용자가 위 여덟과 같은 규약(상업 무료 · 재배포 금지)으로 둘을 받아 두었다.
**원본 mp3 둔 자리는 리포 밖**이고(사용자 내려받기 폴더), md5 를 대조해 받은 것이 맞음을 확인했다.

**사슬은 09-14·09-15 와 같다** — mp3 읽기 → 평준화(머리 0.5초 RMS **0.0512** · 천장 **0.80**) → **ogg 1회 인코딩**.

둘 다 천장에 안 걸려 목표 RMS 에 거의 정확히 앉았다. 열의 머리 RMS 퍼짐은 **0.0490~0.0555** 로 유지된다.

⚠️ **`sfx_ui_click` 이 길이 상한을 넘는다 — 0.997초 · 상한 0.5.**
이 대장이 조달 전에 「버튼은 연타되므로 **0.15초 이하**를 권한다」고 적어 둔 자리이고,
받은 것은 그 **여섯 배 반**이다. **자르지 않았고 판정도 하지 않는다** — 사용자 청취 자리다.
잠재 위험만 적어 둔다: 버튼을 빠르게 누르면 1초짜리가 겹쳐 뭉개진다 — 길이 상한을 묶은 근거(2장) 그대로다.

✅ **임포트 규격이 둘에 먹는다 — 코드에서 확인했다.**
`AudioImportRules.cs` 가 `assetPath.StartsWith(SfxDir)` 로 판정한다 — **파일 목록이 아니라 폴더**에 걸리므로
새 파일도 그대로 먹는다. `sfx_ui_click.ogg.meta` 를 직접 읽어 실물로 확인했다 —
`loadType 0`(Decompress on load) · `compressionFormat 0`(PCM) · `preloadAudioData 1` ·
**`forceToMono 1`** · `loadInBackground 0` 로 나머지 여덟과 **값이 같다**.
`sfx_goal_clear.ogg.meta` 는 아직 없다 — Unity 가 이번 임포트에서 만들면서 같은 값을 넣는다.
