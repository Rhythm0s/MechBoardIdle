### 임포트 설정 (구현-문서·코드 세션의 `AudioImportRules` 가 먹인 결과)

`.meta` 셋(`bgm.meta` · `bgm_battle.ogg.meta` · `bgm_boss.ogg.meta`)이 붙어 이 자리가 채워졌다.
아래는 **`.meta` 를 직접 읽은 값**이며, 정한 것은 문서·코드 세션이고 아트는 옮겨 적기만 한다.

| 항목 | 값(원문) | 뜻 |
|---|---|---|
| `loadType` | `2` | **Streaming** — WebGL 배포에서 통곡을 메모리에 올리지 않는다(사운드 문서 7장 방향과 같다) |
| `compressionFormat` | `1` | Vorbis |
| `quality` | `1` | 100% — 이미 OGG 라 재압축 손실을 더 얹지 않는다 |
| `preloadAudioData` | `0` | 미리 안 읽는다 |
| `loadInBackground` | `1` | 배경 적재 |
| `sampleRateSetting` | `0` | **Preserve Sample Rate** — 파일의 48 kHz 가 그대로 간다 |
| `sampleRateOverride` | `44100` | `sampleRateSetting` 이 0 이라 **쓰이지 않는 값**이다 |
| `forceToMono` | `0` | 스테레오 유지 |
| `normalize` | `1` | 임포트 시 정규화 |
| `3D` | `1` | 기본값 그대로 — BGM 은 2D 로 재생하므로 `AudioSource.spatialBlend` 가 실제를 정한다 |

GUID — `bgm_battle.ogg` `58ba00a0…` · `bgm_boss.ogg` `8bab8546…` · `bgm/` 폴더 `4226045d…`.

**48 kHz 문제는 이로써 닫혔다.** 사운드 문서 1장의 「44.1 kHz」는 효과음(WAV) 규격이고,
BGM 은 `Preserve Sample Rate` 라 표본율을 바꾸지 않는다 — 어긋난 자리가 아니었다.

### 재는 법과 변환 방법 (2026-09-09 · 구현-문서·코드 세션이 사용자 지시로 수행)

- **도구**: Python `soundfile` 0.14.0 (libsndfile 1.2.2). **`ffmpeg`이 없어 `pydub`을 못 썼고**,
  libsndfile 이 mp3 읽기와 OGG/Vorbis 쓰기를 둘 다 해서 **한 라이브러리로 끝냈다.**
- **변환**: `sf.read(mp3)` → `sf.write(ogg, format="OGG", subtype="VORBIS")`.
  표본율은 **그대로 두었다**(44.1/48 kHz 섞여 있다). 채널도 **그대로** — 여덟 다 스테레오다.
- **길이**: 디코드한 표본 수 ÷ 표본율. 도구가 낸 값이 아니라 **파일에서 직접 센 값**이다.

⚠️ **여덟이 전부 길이 상한을 넘는다.** 사운드 문서 2장이 효과음을 **0.5초 이내**로 묶었고
`sfx_fusion`만 2.2초까지 열어 두었는데, 실측은 **1.01초에서 3.97초**다.
✅ **자르지 않았다** — 자르는 것은 사용자 판정이며, 여기는 잰 값만 적는다.
⚠️ **길이를 묶은 근거가 살아 있다**(2장) — 이 게임의 소리는 초당 여러 번 나고
관통탄은 초당 다섯 발이다. **1초짜리가 초당 다섯 번 나면 겹쳐 뭉개진다.**
겹침 상한(잠정 3)이 그 뒤에 오는 두 번째 방어선이지 첫 번째가 아니다.

⚠️ **여덟 다 스테레오다.** 사운드 리스트는 효과음을 **모노**로 적어 두었다.
**바꾸지 않았다** — 섞어 내리는 것도 값을 바꾸는 일이라 판정 자리다.

⚠️ **`sfx_fire_a`만 ogg 가 mp3 보다 크다**(22 KB > 17 KB). 이미 압축된 것을 다시 압축한
자리이며 손실이 겹친다 — **원본을 wav 로 받을 수 있으면 그쪽이 낫다.**

### 임포트 설정 — `AudioImportRules` 가 sfx 에 먹인 값

`OnPreprocessAudio` 가 `Assets/_Project/Audio/sfx` 로 시작하는 경로에
**`DecompressOnLoad` · `PCM` · `preloadAudioData = true`** 를 넣는다.
✅ **2026-09-09 확인 — 여덟 다 먹었다.** `.meta` 여덟이 생겼고 값을 직접 읽었다:

| 항목 | 값(원문) | 뜻 |
|---|---|---|
| `loadType` | `0` | **Decompress on load** — 메모리에 풀어 둔다(BGM 의 `2` = Streaming 과 반대) |
| `compressionFormat` | `0` | **PCM** — 풀어 두므로 압축을 남기지 않는다 |
| `preloadAudioData` | `1` | 미리 읽는다 — 첫 발에서 끊기지 않게 |
| `forceToMono` | `0` | 스테레오 유지(규칙이 채널을 안 건드린다) |
| `loadInBackground` | `0` | 배경 적재 안 함 — 짧아서 필요 없다 |

⚠️ **`.meta` 는 커밋되지 않으므로 이 값은 각자의 Unity 가 임포트할 때마다 다시 먹인다** —
코드가 소스라 리포에 `.meta` 가 없어도 규격이 갈리지 않는다.
