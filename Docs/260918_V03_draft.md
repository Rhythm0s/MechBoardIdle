# 3. 신설 넷

## 3-1. 드롭·마그넷
처치한 자리에 재화가 떨어져 **잠깐 멈췄다가** 로봇에게 빨려 들고 「+n 고철」이 떠오른다.
⚠️ **적립을 여기서 안 한다** — 고철은 `KillRewardRule`, 골드는 `GoldRewardRule` 이
방치 런타임 안에서 이미 했고, 화면은 **그 일이 일어났다는 것을 보이게** 할 뿐이다.
마리당 고철 값도 `IdleSignals` 가 게시한 것을 읽는다(같은 값을 두 자산 경로로 안 읽는다).
⚠️ 코인 스프라이트는 아트 몫이며 **오기 전에는 원형 폴백**이다.

## 3-2. 골드 지갑 — **규칙 신설**
「몬스터 20처치마다 5골드」(사용자 값). `CurrencyWallet.Gold` · 저장 · 활용처 없음.
⚠️⚠️ **남은 처치 수를 저장이 든다**(`SaveDataV1.killsTowardGold`) — 그것이 없으면
19 마리를 잡고 끈 사람이 켤 때마다 0 에서 다시 센다.
⚠️ 값 둘(20 · 5)은 `EconomyConfig` **한 자산에만** 살고 규칙은 수를 안 든다.

## 3-3. 웨이브 스폰 — **규칙 신설 · ⚠️ 가정 · 설계 판정 자리**
⚠️⚠️ **종전 스폰에는 「리젠까지 남은 시간」이 없다.** `index × cadence` 는 늘 0.8초 뒤에
하나가 나오므로 타이머를 걸면 같은 수만 되풀이한다. 묶음과 묶음 **사이의 빈 시간**이
있어야 셀 것이 생긴다. 그래서 **묶음 W, 간격 T** 로 바꿨다.

📌 **평균 속도는 안 바꿨다.** 간격이 0 이면 `W × spawnCadence` 로 끌어오므로
평균 마리/초가 종전과 같다(4 / 3.2 = 1 / 0.8 = 1.25). **값을 지어내지 않고 있는 값에서 끌었다.**
달라지는 것은 **고르게 오던 것이 뭉쳐서 온다**는 것 하나다.

**실측 — S1 Win 유지**: 태그 두 로봇 하네스 `Win 77.7초 · 남은 적 0/100 · 로봇 HP 1000/1000`
(웨이브 전 `81.2초`). 하네스에도 같은 웨이브를 걸었다 — 안 걸면 **하네스는 한 마리씩 오는
판을, 게임은 묶음으로 오는 판을** 돌린다(09-15 에 겪은 「프로브는 초록인데 화면은 낡았다」).

⚠️ **묶음 크기 4 는 가정이다.** 묶음 1 이면 식이 종전과 같아져 **되돌릴 길이 값 하나로 남아 있다.**

# 7. 정정 둘 — 회신문 하나 · 세션 사이 독법 하나

**① 「⚠️ 줄인 것은 타격당 피해뿐이고 충전량·수명은 그대로다」(`260918_V02` 1장 ③)는 틀렸다.**
그때 코드에서 **충전 소모가 피해와 같은 값**이었다 — 피해를 절반으로 줄이면 충전도 절반만
닳아 **수명이 두 배**가 됐다. 「그대로」가 아니라 **반대로 움직이고 있었다.**
고친 것은 `DroneUnit.Fire` 를 **먹는 양과 주는 양으로 가른 것**이고, 그래야 회신문의
문장이 코드에서 참이 된다.

**② 「면이 다름 = 거짓 경고」 — 출처를 바로잡는다.**
⚠️ **이 말은 회신문에 없다.** 계획 세션의 독법이었고(플랜 §85-7 · 세션 메시지),
**구현이 확인 없이 받았다.** 실제로는 하네스가 회전한 판을 돌리는 동안
`BoardController` 가 **제 배치 루프**를 갖고 있어 회전을 무시했다 —
**게임은 회전 없는 판을 돌리고 있었다.** 경고가 맞았고 받아 적은 쪽이 틀렸다.
지금은 `StartingBoardB.Apply` **한 문**으로 들어간다.

📌 **고칠 것은 코드가 아니라 받는 법이다** — 남의 독법을 확인 없이 제 판정으로 삼으면,
그 판정이 회신문에 실려 **출처 없는 사실**이 된다.

📌 **둘 다 같은 뿌리다** — 같은 일을 하는 자리가 둘이면, 한쪽만 보고 한 말이 문서에 남는다.
①은 코드에서, ②는 세션 사이에서 그 일이 났다.

# 9. 리허설 — 볼 것 열둘

| # | 볼 것 |
|---|---|
| 1 | 상단 칩 줄 — 썸네일·닉네임·전투력 / 골드 칩·소리·설정이 **안 겹치는지** |
| 2 | 골드 칩의 「+n/초」가 처치와 함께 움직이는지 |
| 3 | 배지 줄 — S1 · 목표 · 「남은 몬스터 n · 리젠 mm:ss」 |
| 4 | **리젠 타이머가 실제로 줄었다가 묶음이 오는지**(웨이브) |
| 5 | 적 체력이 **발밑 빨간 바**인지 |
| 6 | 로봇 몸 밑 — HP 수치 · 보호막 수치 · 회피 눈금 |
| 7 | 태그 원형 둘레의 **적재 링**이 차는지 |
| 8 | 태그 → **자동 토글** → 합체 차례가 세로로 서는지 · 셋 다 눌리는지 |
| 9 | 처치할 때 **재화가 떨어져 빨려 들고** 「+n 고철」이 뜨는지 |
| 10 | 스무 마리쯤에서 **골드가 하나 떨어지는지** |
| 11 | 우하단 **마일스톤 카드** — 목표 둘 체크 · 「보상 받기」가 한 번만 눌리는지 |
| 12 | 조립 화면 상단 — **고철 수치 + 문제 목록**(문제가 없으면 「문제 없음」) |

⚠️ 좌측 「i」는 **개발 빌드에서만** 보인다. 웹빌드에서 안 보이는 것이 정상이다.
