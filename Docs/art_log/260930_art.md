# 2026-09-30 아트 로그 (구현-아트 세션 소유)

**사용자 육안 셋** — 포트 마커 셋 승인 · 작은 커넥터 `c00` 승인 · `mob_cannon` 면 선택.

## 되물은 둘 — 글자대로 옮겼으면 둘 다 흠이 됐다

| 사용자 원문 | 글자대로 옮기면 | 되물어 확정된 것 |
|---|---|---|
| 「포트 커넥터 c00 승인」 | `c00` 은 **주황 위쪽 화살표 = 입력용 한 장**이다. 출력용이 빈 채로 닫힌다 | 출력용은 **`c01`**(같은 호출에서 나온 붉은 아래쪽 화살표) |
| 「south, north, north-west, south-east 승인」 | **지금 쓰는 `east`·`west` 가 지워진다**(둘 다 승인·설치본) | **「쓰는 넷만 남긴다」** — 대각 넷을 지운다 |

**아트는 판정하지 않지만, 판정이 배선을 끊을 때는 되묻는다.**

## `.meta` 가 안 생겨 두 시간 막혔다 — 잠금 파일

새 PNG 둘의 `.meta` 가 안 만들어졌다. 까닭은 **Unity 에디터(PID 49540)가 프로젝트 잠금을 쥐고 있어서**였고,
배치모드가 「Successfully changed project path」 직후 **return code 1** 로 끝났다.
**문서·코드 세션의 배치모드도 같은 잠금에 걸려 있었다** — 내 쪽만의 문제가 아니었다.

`CloseMainWindow` 로 창 닫기 신호를 보냈으나 안 닫혔다(확인 창이 떠 있었다).
**강제 종료는 안 했다** — 저장 안 된 편집이 날아가는 되돌릴 수 없는 일이라 **사용자 지시를 기다렸다.**
사용자가 강제 종료한 뒤 `Temp/UnityLockfile` 을 지우고 배치모드를 돌리니 **exit 0** 으로 끝나고 `.meta` 둘이 생겼다.

**확인한 것** — 둘 다 `TextureImporter` 가 들어찼고 형제 자산 `port_input` 과 값이 같다
(`spriteMode: 1` · `filterMode: 0`(점) · `spritePixelsToUnits: 192`).
guid — 입력 `fb0a7320…` · 출력 `081c6157…`.
**09-21 에 반쪽 `.meta` 를 커밋한 적이 있어, 이번엔 `TextureImporter` 유무를 세어 보고 커밋했다.**
