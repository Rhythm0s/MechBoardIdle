# 사용자 시트 대기 목록 — `Tables/*.xlsx` ↔ `GameData/*.csv` (2026-10-17 · 코드 세션 · 촬영 뒤 큐 ⓔ)

**왜 있나.** 사람이 고치는 것은 `Tables/<NAME>_DATA.xlsx`이고 게임이 읽는 것은 `Assets/_Project/GameData/<NAME>_DATA.csv`다(`Tables/xlsx_to_csv.py`).
10-13부터 10-17까지 확정값을 **CSV에 먼저 임시로** 넣었다(시트는 사용자가 고친다). 그래서 지금 시트로 `xlsx_to_csv.py`를 돌리면 **아래 칸이 모두 옛 값으로 되돌아간다.**

**재는 법.** `xlsx_to_csv.py`의 읽기(`data_sheet`)로 시트를 읽어 CSV와 칸마다 대조했다(숫자는 값으로 비교 · `Dev_` 열 제외). 리포 `1e03503` 기준.
대조 결과: 16장 중 **7장 · 76칸이 다르다**. 9장(ECONOMY · ENHANCE · LOGISTICS · META · MODULE · NODE · RECIPE · TEXT · WEAPON)은 같다.

⚠️ **값을 짓지 않았다.** 「CSV(지금)」 열이 게임이 쓰는 값이고, 시트에 옮길 값이 바로 그것이다.

## 6. 확인만 — `balance_v4.json` 주제 글자 거울(큐 ⓕ)

`balance_v4.json` `stages[].topic` 여섯 = 「벨트 연결 · 모듈 배치 · 물류 재설계 · 마운트 강화 · 태그 학습 · 합체·버스트」 — **CSV `TID_Topic`과 같다** ✅(`6297399`).
시트는 아직 괄호 글자다(1번 표). 시트를 고치기 전에 생성기를 돌려도 json 쪽은 이미 같은 글자라 괄호가 되살아나지 않는다.

## 7. 시트를 고친 뒤

```
python Tables/xlsx_to_csv.py
```
그다음 `git diff Assets/_Project/GameData`가 **비어 있어야** 한다(시트 = 지금 CSV). 남는 줄이 있으면 그 칸이 아직 다르다.
