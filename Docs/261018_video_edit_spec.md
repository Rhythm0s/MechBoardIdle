## 1. 역할과 경계
- **하는 일**: 클립 선별·컷 편집·구간 배열·자막·타이틀/엔드 카드·배경음 합성·내보내기·검수.
- **안 하는 일**: 게임 코드·자산·리포 `Assets/`·QA 시트·Notion 편집 0. 리포에는 이 작업의 산출 폴더와 로그만 쓴다. 다른 세션(코드·노션)에 직접 말 걸지 않는다 — 코드 사실이 필요하면 플랜 세션에 묻는다.
- **원칙**: 원본 클립은 **절대 덮어쓰거나 지우지 않는다**(복사본으로만 작업). 수치(요구치·HP 등)는 영상 자막에 넣지 않는다(촬영 스크립트 규칙 — 숫자는 설계 판정 중). 화면 안 글자(HUD)는 그대로 보여 준다.
- **보고**: 단계 끝마다 플랜 세션에 SendMessage 한 통 — ① 산출 파일 경로·길이·해상도 ② 바꾼 것 ③ 판단 필요한 것(컷 선택·자막 문안·BGM·규격) ④ 사용자가 그 창에서 직접 지시한 것(원문). 사용자가 편집 세션 창에서 직접 말하면 그것이 우선이고, 플랜에 그대로 전달한다.

## 6. 도구와 방법
- 1순위 `ffmpeg`/`ffprobe`(설치 여부 먼저 확인 · 없으면 설치는 사용자 몫 — 묻는다). 자르기 `-ss/-to` 재인코딩 · 이어 붙이기 concat demuxer · 자막은 `subtitles=` 필터로 굽거나(burn-in · 기본) SRT 별도 ⚠️ · 가로 규격이면 `pad`/`overlay`로 가운데 배치.
- 2순위: ffmpeg를 못 쓰면 **편집 결정표(EDL)와 자막 SRT만** 완성해 사용자가 GUI 편집기(DaVinci Resolve 등)에서 그대로 따라 자르게 한다.
- Python 보조 스크립트는 `tools/`에 두고 리포 밖 작업 폴더에서 돌린다. 원본 폴더에서 스크립트를 실행하지 않는다.
- 미리보기: 구간별 10초 발췌 mp4를 먼저 내고 플랜 세션 → 사용자 확인 뒤 전체 조립.

## 7. 검증(완성본마다)
1. `ffprobe`로 길이 1:20 ± 2초 · 해상도 · fps · 오디오 트랙 확인.
2. 구간 경계 시각이 §5 표와 ±0.5초 안.
3. C구간 「수치 두 줄」 프레임이 살아 있는가(스크린샷 1장).
4. 자막 글자 잘림·겹침 0(각 구간 1프레임씩 스크린샷 → 플랜에 첨부 경로).
5. 배속·색 보정 없음.
6. 원본 폴더 해시가 작업 전과 같음(건드리지 않았다는 증거).
